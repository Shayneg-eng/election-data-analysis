# US Election Data Analysis

Modeling and analysis of US presidential elections (1960–2024).

## Files
| File | Role |
|---|---|
| `election_model.py` | Builds and evaluates the election model |
| `extract_candidates.py` | Parses candidate data from the raw dataset |
| `us_presidential_elections_1960_2024.csv` | Source dataset |

## Run it
```bash
python -m pip install pandas numpy scikit-learn
python election_model.py
```
